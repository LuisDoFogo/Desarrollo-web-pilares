# Página personal de SpringMX

Página personal de Luis Enrique Garduño Guzman para la actividad de Pilares. Está hecha con HTML5 y CSS3 básicos.

## Contenido

- Presentación personal y avatar.
- Sección «Sobre mí».
- Proyecto interactivo de Scratch incrustado en la página.
- Diseño adaptable a computadoras y celulares.

## Archivos

- `index.html`: contenido y estructura de la página.
- `styles.css`: colores y estilos.
- `images/faraam_knight.jpg`: avatar personal.

## Cómo abrir la página

Abre `index.html` en un navegador. También puedes abrir la carpeta en Visual Studio Code e iniciar Live Server desde `index.html`.

El proyecto de Scratch necesita conexión a internet para mostrarse y funcionar.
